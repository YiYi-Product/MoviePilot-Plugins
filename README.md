# YiYi MoviePilot 插件

面向 MoviePilot v2 的 YiYi Media 集成插件。插件通过一次性配对码建立双向授权，自动添加一个 Emby 类型的 YiYi Media 媒体服务器。

## 配置

1. 在 MoviePilot 的插件市场添加本仓库地址：`https://github.com/YiYi-Product/MoviePilot-Plugins`，安装 **YiYi Media**。
2. 在 YiYi **系统配置 → 集成与高级 → MoviePilot 集成**中填写连接名称，生成配对码。配对码有效期为 5 分钟，只展示一次。
3. 在插件中填写 **YiYi 站点地址**和**配对码**，打开「启用插件」并保存。
4. 如果 MoviePilot 的 `APP_DOMAIN` 未配置，填写 **MoviePilot 回调地址**。该地址是 YiYi 能访问的 MoviePilot 网页入口，可包含反向代理路径前缀。填写的是站点入口，不需要附加 API 路径。
5. 保存约 3 秒后开始连接。插件自动填写媒体服务器地址和独立密钥，成功后显示「双向连接成功」。检查任务每分钟运行一次。

插件发布新版本后，在 MoviePilot 插件市场刷新并升级 **YiYi Media** 即可获取更新；本地源码可使用 MoviePilot 的本地插件仓库功能调试。

配对完成后会清空插件配置中的配对码。重启保留授权，重复检查不会重复添加服务器。同名的现有服务器会保留；插件只维护带有本插件实例标识的记录，媒体库同步选择和同步间隔也会保留。

媒体服务器名称自动使用 YiYi **系统配置 → 系统名称**，无需在插件中填写。插件升级后会同步更新已有服务器的名称；修改 YiYi 系统名称后，下次每分钟连接检查时会自动同步。如果名称与其它服务器相同，会附加实例标识以避免覆盖。系统名称暂时读取失败时保留现有服务器配置，稍后自动重试。

配置页顶部显示连接状态；连接信息在宽屏下分为两列，窄屏下自动单列排列。「连接管理 · 解除绑定」默认收起，展开并打开解除开关、保存后才会撤销授权。

## 地址与网络

- YiYi 地址使用管理站点入口，无需配置 media 内部地址、端口或抓包令牌。YiYi 需要运行包含 MoviePilot 集成功能的版本。
- 双方需要互相可达。MoviePilot 出站请求验证 HTTPS 证书，不接受重定向；自签证书需先在运行环境中建立信任。
- YiYi 回调默认允许普通私网地址。回环、链路本地地址需要 YiYi 服务端的主机白名单；云元数据地址、通配地址和多播地址始终拒绝。
- 修改插件中的回调地址并保存后，会更新现有连接，继续验证。修改 YiYi 站点地址前，需要先解除旧绑定。
- 请求成功但 YiYi 无法回调时，媒体服务器仍可用于查询，插件明确显示回调未完成并继续重试。

## 授权与解除

两边使用独立随机凭据，均不使用管理员密码、浏览器会话、MoviePilot 全局 `API_TOKEN` 或 YiYi 内部服务令牌。

YiYi 保存入站凭据的 SHA-256 哈希，回调凭据加密保存。MoviePilot 按插件数据方式持久化凭据，媒体服务器的密钥使用 MoviePilot 原生配置存储机制；其数据库和备份应按敏感配置管理。

- 在 YiYi 点「撤销授权」：立即拒绝旧凭据，同时通知插件清除授权并停用对应服务器。如果 MoviePilot 离线，恢复连接后最多约 1 分钟检测到撤销并清理。
- 在插件打开「解除双方绑定」并保存：通知 YiYi 撤销，再清除本地授权。如果 YiYi 不可达，插件会提示在 YiYi 管理页补做撤销。
- 单纯关闭插件：停用并清除该媒体服务器中的密钥，但保留插件配对数据，供再次启用恢复。
- 卸载插件前建议先解除双方绑定。卸载本身不会保证远端授权已撤销。

## 本期范围

支持双向授权、连接状态检查、自动添加媒体服务器、现有 Emby 媒体库查询，以及海报、背景图和 Logo 展示。图片兼容需要 YiYi 服务端包含对应更新；已有配对可直接使用，无需重装插件。图片地址关联有效授权连接，只提供授权管理员可访问条目的图片，撤销连接后停止响应新的图片请求。

集成入口拒绝写操作、播放、下载、刷新和后台管理。MoviePilot 中的播放跳转和依赖真实文件路径的功能不在本期范围。

YiYi 调用插件的接口目前只有连接检查与解除绑定。尚未开放求片、订阅创建或用户账号自动互建；后续求片功能可在同一授权连接上增加明确的业务接口。

```bash
python3 -m venv .venv
.venv/bin/python -m pip install -r requirements-dev.txt
.venv/bin/python -m pytest tests
```

测试通过替身隔离 MoviePilot 的数据库、全局单例和外部网络，不读写真实 MoviePilot 配置。
